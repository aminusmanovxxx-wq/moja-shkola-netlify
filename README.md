# Моя школа — учебный помощник

Готовое адаптивное web-приложение для развёртывания на Netlify. Интерфейс написан без тяжёлого UI-фреймворка, чтобы работать на недорогих Android-телефонах.

## Открыть / опубликовать

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/aminusmanovxxx-wq/moja-shkola-netlify)

В Netlify импортируй этот репозиторий (ветка `main`) и используй настройки из `netlify.toml`. После импорта каждая успешная отправка в `main` будет запускать автоматическую сборку.

ИИ подключается через Netlify AI Gateway на поддерживаемом credit-based тарифе: после первого production-деплоя оставь AI Features включённым, тогда Netlify сам предоставит серверные учётные данные. Если Gateway недоступен в тарифе/аккаунте, можно добавить собственный `OPENAI_API_KEY` в Netlify → Project configuration → Environment variables. Никогда не помещай ключ в Git или клиентский код. Облачная синхронизация доступна после публикации Netlify Functions; один и тот же облачный код нужно использовать на каждом устройстве.


## Что уже реализовано в коде

- Фиксированная нижняя навигация: Главная, Расписание, крупная центральная вкладка ИИ-помощник, ДЗ, Настройки. Страница не прокручивается целиком; длинные панели прокручиваются внутри активной вкладки. Масштабирование браузера намеренно не запрещено.
- Первичная настройка в 3 шага: имя и необязательная фамилия, авто/ручной стиль, 10 цветов + собственная двухцветная палитра, светлая/тёмная/тёмно-синяя тема, запрос разрешений по явному действию.
- Небольшая реальная анимация локальной подготовки и приветственная сцена по времени суток. Загрузка не держит человека 5–13 минут искусственно и не говорит, будто модель переобучена.
- Анимированный Live-режим. Первый урок — 08:30, длительность уроков 45 минут; перемены 10/10/15/15/10/5 минут. При текущей перемене метка плавно увеличивается до размера карточки урока и подсвечивается.
- Импорт скриншотов расписания и ДЗ через серверную ИИ-функцию, предварительный просмотр изображения на полный экран, ручной ввод как fallback, поддержка разных классов/дней.
- Задания сохраняются в localStorage текущего браузера. Задания на завтра могут автоматически получать подготовленные решения на сервере, но решения скрыты до нажатия пользователем.
- Проверка каждые 10 минут касается только доступных приложению локальных заданий; она не извлекает данные из МЭШ/школьного дневника без официального API.
- Уведомления за 5 минут запускаются с разрешения браузера, пока страница открыта. Push после закрытия страницы не обещается.
- Netlify Function `netlify/functions/assistant.mjs`: серверный endpoint для разбора скриншотов, подготовки объяснений и чата, ограничение размера изображения и простое ограничение частоты запросов.
- Отдельная вкладка «Фото ИИ» с встроенным Hugging Face SmolVLM 256M WebGPU анализатором; iframe загружается только после нажатия пользователя и имеет ссылку для открытия отдельно.
- Тесты границ расписания: 08:30, 09:15, переход на второй урок в 09:25, пятый урок заканчивается в 13:05, шестой — в 14:00, последняя перемена до 14:05.

## Что нужно настроить для настоящего ИИ

1. Развернуть весь репозиторий через Netlify Git continuous deployment или Netlify CLI. Простая публикация только файлов `public/` не публикует серверные функции.
2. На credit-based тарифе Netlify оставь включённым **AI Features** и выполни первый production-деплой: после этого встроенный AI Gateway может предоставить `OPENAI_API_KEY` и `OPENAI_BASE_URL` функции автоматически. По умолчанию используется `gpt-4o-mini`; доступность моделей и стоимость зависят от Gateway/аккаунта. Если AI Gateway недоступен, добавь собственный `OPENAI_API_KEY` в Netlify с областью действия **Functions**. Секрет хранить только на сервере, не в `public/`, не в чате и не в Git.
3. Для защищённого импорта расписания добавить `SCHEDULE_ADMIN_PIN` с областью **Functions** и установить согласованный PIN. Серверная функция сверяет PIN; в клиентский JavaScript PIN не встроен. Если переменная не установлена — сервер блокирует импорт. Не храните реальное значение в репозитории.
4. После изменения переменных окружения сделать новый deploy, чтобы функция получила новые значения.

Пока Netlify AI Gateway не активирован первым production-деплоем (или если тариф не поддерживает AI Features) и не задан собственный `OPENAI_API_KEY`, серверный анализ скриншотов, генерация решений и чат честно сообщают, что серверный ИИ ещё не подключён. Вкладка «Фото ИИ» открывает внешний SmolVLM WebGPU анализатор и не требует ключа OpenAI, однако модель загружается поставщиком внутри внешнего сайта. При первом использовании браузер может скачать модельные файлы; веса не переобучаются. Анализатор открыт в cross-origin iframe, поэтому основной сайт не может автоматически передать ему выбранный файл или прочитать результат. Выбери изображение внутри самого анализатора, а затем скопируй его вывод в форму ДЗ. Встроенный анализатор зависит от совместимости браузера с WebGPU и может работать медленно или не запуститься на некоторых устройствах.


## Локальный анализ фотографий через Hugging Face

Вкладка «ИИ-помощник → Фото ИИ» открывает предоставленный пользовательский WebGPU-анализатор. Поскольку это внешний сайт во встроенном `iframe`, он изолирован политикой браузера: основное приложение не может автоматически передать ему выбранный в другой вкладке файл или программно читать вывод. Поэтому изображение загружается внутри анализатора, а его результат при необходимости копируется обратно в ДЗ. Открытие iframe запускается только после действия пользователя, чтобы не скачивать модельные файлы незаметно через мобильный интернет.

Официальная страница Space: https://huggingface.co/spaces/HuggingFaceTB/SmolVLM-256M-Instruct-WebGPU. В карточке Space указаны модель `HuggingFaceTB/SmolVLM-256M-Instruct` и лицензия Apache-2.0. WebGPU запускает inference на поддерживаемом устройстве; скачивание весов — это загрузка уже обученной модели, **не переобучение и не обучение новой модели**. Поддержка зависит от браузера и устройства; подробности: https://huggingface.co/docs/transformers.js/guides/webgpu.

## Развёртывание

### Рекомендуемый путь (с функциями)

- Загрузите содержимое папки проекта в репозиторий GitHub.
- В Netlify выберите **Add new project → Import an existing project**, подключите репозиторий.
- Build command: `npm test && npm run typecheck`
- Publish directory: `public`
- Functions directory: `netlify/functions`
- Установите переменные окружения из предыдущего раздела и нажмите Deploy.

### Только статический предпросмотр

`public/` можно отдельно выложить как статический сайт, но serverless-функции при таком способе не появятся. Поэтому это не включает настоящее распознавание изображений и ИИ-ответы. Для полного приложения используйте Git/CLI deploy.

## Личные данные

Профиль, расписание и список ДЗ сохраняются в localStorage выбранного браузера. При нажатии «Анализировать» текст и выбранное изображение отправляются в серверную функцию и внешнюю модель ИИ; не загружайте скриншоты с чужими личными данными. Внешний школьный дневник не подключён.

## Проверка локально

```bash
npm test
npm run typecheck
```

Для локального запуска serverless-функции установите Netlify CLI и запустите `netlify dev`.


## Облачная синхронизация между устройствами

В настройках открой блок «Облачная синхронизация» и нажми «Создать / проверить облако». Скопируй сгенерированный секретный код. На другом устройстве открой тот же опубликованный сайт, вставь код и нажми «Подключить код». После этого изменения отправляются в Netlify Blobs автоматически с небольшой задержкой.

Код — это секрет доступа ко всем данным профиля; не отправляй его посторонним. Без опубликованной Netlify Function и успешно собранной зависимости `@netlify/blobs` облако не заработает. При первом подключении другого устройства данные из облака заменяют локальные данные на нём. Это простая синхронизация «последняя запись побеждает», а не совместное редактирование.

## ИИ и анализ изображений

Серверный ИИ использует Netlify AI Gateway на поддерживаемом credit-based тарифе: после первого успешного production-деплоя при включённых AI Features Netlify может автоматически передать функции серверные учётные данные. Если шлюз недоступен, можно настроить собственный `OPENAI_API_KEY` в Netlify с областью **Functions**. Пока шлюз не активирован и собственного ключа нет, чат и серверный анализ изображений честно сообщат, что ИИ не настроен. Текст расписания и ДЗ может разбираться локальным шаблонным анализатором, но это **не ИИ** и результат нужно проверить. Для распознавания изображений без ключа используется отдельный SmolVLM WebGPU iframe.

При запуске не имитируется скачивание пакетов: приложение не устанавливает пакеты в браузере. Реальная загрузка весов SmolVLM происходит внутри внешнего анализатора и зависит от сети и устройства; мы не можем принудительно установить точное время загрузки в две минуты.
