# Моя Школа+ — учебный помощник

Адаптивное PWA-приложение на русском языке для расписания, домашних заданий и учебного ИИ. Интерфейс сделан без тяжёлого UI-фреймворка для телефонов, включая бюджетные Android-устройства.

## Самый простой способ опубликовать

**Вариант A — подключить готовый GitHub-репозиторий:**

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/aminusmanovxxx-wq/moja-shkola-netlify)

1. Открой кнопку Deploy to Netlify и войди в Netlify.
2. Подтверди импорт репозитория `aminusmanovxxx-wq/moja-shkola-netlify`, ветка `main`.
3. Оставь параметры из `netlify.toml`: команда сборки `npm test && npm run typecheck`, каталог публикации `public`, функции `netlify/functions`.
4. Запусти production deploy. Дальнейшие коммиты в `main` публикуются автоматически, если связь GitHub–Netlify активна.

**Вариант B — из ZIP:** распакуй архив, загрузи файлы в свой GitHub-репозиторий, затем импортируй этот репозиторий в Netlify. Не загружай ZIP как единственный статический файл: функции ИИ и синхронизации должны попасть в развёртывание.

## Включить ИИ с бесплатной квотой

В проект уже встроена поддержка Gemini API. Бесплатная квота зависит от доступной модели и текущих лимитов Google; это не безлимитный сервис. На бесплатном тарифе Google может использовать запросы для улучшения своих продуктов, поэтому **не отправляй в ИИ фотографии с полными именами, адресами, паролями, оценками других учеников или другой конфиденциальной информацией**. Подробности и ограничения см. в официальной документации: https://ai.google.dev/gemini-api/docs/pricing.

1. Открой официальную страницу Google AI Studio: https://aistudio.google.com/apikey и создай **собственный** API-ключ. Здесь нельзя использовать чужие публичные ключи: они могут быть украдены, отключены, а их владелец контролирует доступ.
2. В Netlify открой **Project configuration → Environment variables** и создай переменную:
   - Name: `GEMINI_API_KEY`
   - Value: твой ключ из AI Studio
   - Scope: Functions / Runtime (или All, если интерфейс предлагает только общий вариант).
3. Сохрани переменную и запусти новый production deploy.
4. Готово: серверная функция использует модель `gemini-3.5-flash-lite` по умолчанию. При необходимости модель можно поменять с помощью серверной переменной `GEMINI_MODEL` на модель, доступную твоему аккаунту и бесплатной квоте.

**Ключ не должен появляться в GitHub, `.env.example`, HTML, JavaScript в папке `public/`, ZIP, скриншотах или чатах.** Он нужен только в настройках Netlify. Если AI Studio требует выполнения возрастных условий или подтверждения, попроси родителя/опекуна помочь с настройкой; не обходи требования сервиса.

Дополнительно поддерживается OpenAI-совместимый ключ в `OPENAI_API_KEY`, но это необязательно.

## Что есть в приложении

- Нижняя навигация: Главная, Расписание, ИИ-помощник, ДЗ и Настройки.
- Первичная настройка имени, темы, цвета и стиля; приветствие меняется в зависимости от времени суток.
- Live-расписание с первым уроком в 08:30, переменами и напоминаниями в открытой вкладке.
- Анализ загруженного изображения расписания и домашнего задания через серверную ИИ-функцию.
- Учебный чат с краткими пошаговыми объяснениями.
- Локальный фото-анализатор SmolVLM/WebGPU во вкладке «Фото ИИ» (внешний сайт, запускается по нажатию пользователя).
- Облачная синхронизация через Netlify Blobs: создай код в настройках, скопируй его на другое устройство. Этот код предоставляет доступ ко всем сохранённым данным профиля — не передавай его другим.
- Защищённый импорт расписания через серверную переменную `SCHEDULE_ADMIN_PIN`.

ИИ, облако и серверный импорт работают только при полноценном развёртывании с функциями. Статическая публикация одной папки `public/` их не включает.

## Проверка проекта

Требуется Node.js 22 или новее.

```bash
npm install
npm test
npm run typecheck
```

## Важные ограничения

- Бесплатная квота AI-провайдера имеет лимиты, может измениться или закончиться.
- При бесплатном использовании Gemini содержимое запросов может использоваться Google для улучшения продуктов; не отправляй чувствительные данные.
- Облачная синхронизация работает только после публикации Netlify Functions и использует принцип «последняя запись побеждает».
- Напоминания браузера работают, пока приложение активно; push после закрытия вкладки отдельно не настроен.
- Приложение не подключено к школьному дневнику и не извлекает оценки/задания из него автоматически.
