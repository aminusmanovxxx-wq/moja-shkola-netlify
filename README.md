# Моя Школа+ — учебный помощник

Адаптивное PWA-приложение на русском языке для расписания, домашних заданий и учебного ИИ. Интерфейс без тяжёлого UI-фреймворка, рассчитан в том числе на бюджетные Android-устройства.

## 1. Опубликовать проект

Открой кнопку и войди в Netlify:

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/aminusmanovxxx-wq/moja-shkola-netlify)

Подтверди импорт репозитория `aminusmanovxxx-wq/moja-shkola-netlify`, ветку `main`. Оставь настройки из `netlify.toml`: build command `npm test && npm run typecheck`, publish directory `public`, functions directory `netlify/functions`. Запусти production deploy. После настройки Git continuous deployment новые коммиты в `main` должны публиковаться автоматически.

## 2. ИИ без собственного API-ключа

В проект интегрирован **Netlify AI Gateway**. Он передаёт серверным функциям свои учётные данные автоматически; не нужно создавать отдельный аккаунт у OpenAI/Gemini или вставлять ключ в код. Используется модель `gpt-4o-mini` для чата и обработки изображений. Это настоящий удалённый ИИ, а не заготовленные ответы. Официальные инструкции:
- Как пользоваться AI Gateway без API-ключа: https://main--www.netlify.com/knowledge-base/how-to-call-openai-claude-or-gemini-without-api-keys/
- Общая документация AI Gateway: https://docs.netlify.com/build/ai-gateway/overview/
- Текущие цены и модели: https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/pricing-for-ai-features/

**Обязательное условие:** у проекта должен быть хотя бы один успешный production deploy, а AI Features должны оставаться включёнными. После этого Netlify Gateway передаёт `OPENAI_API_KEY` и `OPENAI_BASE_URL` среде выполнения Functions автоматически. Если шлюз ещё не активирован, приложение выдаст понятную ошибку вместо фиктивного ответа.

### Что значит «бесплатно»

На тарифе Netlify Free включено **300 кредитов в месяц**, которые расходуются на использование платформы, включая ИИ. AI Gateway списывает кредиты по цене фактических токенов модели: $1 использования ИИ соответствует 180 кредитам. Это не безлимитный тариф, но отдельный провайдер и отдельный API-ключ не нужны. Чтобы не допустить незапланированных платежей, не включай автоматическое пополнение и не покупай дополнительные пакеты кредитов. После исчерпания квоты ИИ может перестать отвечать до следующего периода. Следи за Usage & billing в Netlify.
- Тарифы: https://www.netlify.com/pricing/
- Расчёт стоимости AI Gateway: https://docs.netlify.com/manage/accounts-and-billing/billing/billing-for-credit-based-plans/pricing-for-ai-features/

### Если после публикации ИИ не включился

1. Убедись, что был именно production deploy, а не Deploy Preview.
2. Проверь Netlify → team settings → AI Features: функция должна быть включена.
3. Не добавляй случайный пустой `OPENAI_API_KEY` или сторонний ключ как переменную проекта: собственные переменные могут отключить автоматическую подстановку Gateway.
4. После изменения настроек сделай новый production deploy.
5. Проверь журнал Functions и квоту в Usage & billing. Если аккаунт не поддерживает Gateway или фича недоступна, потребуется решение от владельца команды Netlify; код сам не может включить недоступную возможность аккаунта.

## Что реализовано

- Нижняя навигация: Главная, Расписание, ИИ-помощник, ДЗ и Настройки.
- Первичная настройка профиля, темы и цветов; приветствие по времени суток.
- Live-расписание с первым уроком в 08:30, переменами и напоминаниями в открытой вкладке.
- Серверный учебный чат, извлечение расписания/домашних заданий с изображений и пошаговые объяснения.
- Отдельный фото-анализатор SmolVLM/WebGPU во вкладке «Фото ИИ». Это внешняя модель в cross-origin iframe; при запуске её веса не переобучаются, и основной сайт не может автоматически передавать туда выбранный файл или читать результат.
- Облачная синхронизация Netlify Blobs: создай секретный код в Настройках и введи его на другом устройстве. Код даёт доступ к данным профиля — не передавай его посторонним.
- Защищённый импорт расписания через серверную переменную `SCHEDULE_ADMIN_PIN`.
- GitHub Actions запускает автоматические тесты, проверяет синтаксис и формирует ZIP-архив.

Полноценное развёртывание Netlify Functions обязательно. Обычная публикация только папки `public/` не включает серверный ИИ и синхронизацию.

## Проверка

Требуется Node.js 22 или новее:

```bash
npm install
npm test
npm run typecheck
```

## Ограничения и приватность

- Бесплатная квота имеет месячный лимит и расходуется совместно с другими функциями Netlify.
- Не отправляй в ИИ пароли, адреса, фото с личными данными других учеников и другую конфиденциальную информацию.
- Netlify заявляет, что AI Gateway не сохраняет prompts и outputs; проверь актуальную документацию безопасности: https://docs.netlify.com/build/ai-gateway/overview/. Другие части сайта и хостинга имеют собственные настройки хранения и журналирования.
- Облачная синхронизация работает по принципу «последняя запись побеждает», а не как совместный редактор.
- Уведомления браузера требуют разрешения; push после закрытия страницы отдельно не настроен.
- Приложение не подключено к школьному дневнику и не считывает оценки или задания автоматически.
