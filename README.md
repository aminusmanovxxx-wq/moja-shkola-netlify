# Моя Школа+ — учебный помощник

Адаптивное PWA-приложение на русском языке для расписания, домашних заданий и учебного ИИ. Интерфейс без тяжёлого UI-фреймворка, рассчитан в том числе на бюджетные Android-устройства.

## 1. Опубликовать проект

Открой кнопку и войди в Netlify:

[![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository=https://github.com/aminusmanovxxx-wq/moja-shkola-netlify)

В Netlify подтверди импорт репозитория `aminusmanovxxx-wq/moja-shkola-netlify`, ветку `main`. Оставь настройки из `netlify.toml`: build command `npm test && npm run typecheck`, publish directory `public`, functions directory `netlify/functions`. Запусти production deploy. После настройки Git continuous deployment новые коммиты будут публиковаться автоматически.

## 2. Подключить бесплатный ИИ (однократно)

В проект уже интегрирован Cloudflare Workers AI через серверную функцию Netlify. Для плана Workers Free Cloudflare указывает бесплатное выделение **10 000 Neurons в сутки**; это дневная квота, а не безлимит. При исчерпании запросы могут временно не выполняться. Официальные источники:
- Цены и бесплатное выделение: https://developers.cloudflare.com/workers-ai/platform/pricing/
- Создание API-токена и получение Account ID: https://developers.cloudflare.com/workers-ai/get-started/rest-api/
- Модель Gemma 4 (чат и анализ изображений): https://developers.cloudflare.com/ai/models/%40cf/google/gemma-4-26b-a4b-it/

Попроси родителя/опекуна или владельца аккаунта выполнить настройку доступа к Cloudflare, если аккаунт требует согласия совершеннолетнего. Не обходи возрастные или аккаунтные требования.

### Получить два значения

1. В Cloudflare Dashboard открой **Workers AI** → **Use REST API**.
2. Создай токен Workers AI и скопируй Account ID. Токен должен иметь только необходимые разрешения Workers AI для запуска модели.
3. В Netlify открой **Project configuration → Environment variables** и добавь две переменные, с областью действия **Functions** (или All, если отдельно выбрать Functions нельзя):
   - `CLOUDFLARE_ACCOUNT_ID` — Account ID из Cloudflare.
   - `CLOUDFLARE_API_TOKEN` — новый API-токен Cloudflare.
4. Сохрани значения и запусти новый production deploy.

Токен не нужно сообщать мне, класть в ZIP, вставлять в JavaScript/HTML или коммитить в GitHub. Серверная функция читает его только из переменных окружения Netlify. Рекомендуется отдельный токен с минимальными разрешениями; если токен случайно стал публичным, отзови его и создай новый.

По умолчанию используется `@cf/google/gemma-4-26b-a4b-it`, мультимодальная модель с поддержкой текста и изображений. Если модель станет недоступна для аккаунта, поменяй `CLOUDFLARE_MODEL` на модель с нужными возможностями, доступную в актуальном каталоге Cloudflare. Не все модели обязательно доступны в бесплатном плане.

## Что реализовано

- Нижняя навигация: Главная, Расписание, ИИ-помощник, ДЗ и Настройки.
- Первичная настройка профиля, темы и цветов; приветствие по времени суток.
- Live-расписание с первым уроком в 08:30, переменами и напоминаниями в открытой вкладке.
- Серверный учебный чат, извлечение расписания/домашних заданий с изображений, структурированные объяснения.
- Отдельный локальный фото-анализатор SmolVLM/WebGPU во вкладке «Фото ИИ», который открывается по действию пользователя. Его веса не переобучаются при запуске; это внешняя модель во cross-origin iframe, поэтому основной сайт не может автоматически передавать туда загруженные файлы или читать его результат.
- Облачная синхронизация Netlify Blobs: создай секретный код в Настройках и введи его на другом устройстве. Код даёт доступ к данным профиля — не передавай его посторонним.
- Защищённый импорт расписания через серверную переменную `SCHEDULE_ADMIN_PIN`.
- GitHub Actions запускает автоматические тесты, проверяет синтаксис и формирует ZIP-архив.

Полноценное развёртывание Netlify Functions обязательно. Обычная публикация только папки `public/` не включает серверный ИИ и синхронизацию.

Требуется Node.js 22 или новее:


## Ограничения и приватность

- Бесплатная квота имеет лимиты и может быть изменена провайдером.
- Не отправляй ИИ пароли, адреса, фотографии с личными данными других учеников или другие конфиденциальные сведения.
- Cloudflare Workers AI документирует обработку запросов без их хранения после выполнения вывода; см. https://developers.cloudflare.com/workers-ai/platform/data-usage/. Остальные части сайта и хостинга имеют собственные настройки хранения и журналирования.
- Облачная синхронизация работает по принципу «последняя запись побеждает», а не как совместный редактор.
- Уведомления браузера требуют разрешения и лучше работают, когда приложение открыто. Push после закрытия страницы отдельно не настроен.
- Приложение не подключено к школьному дневнику и не считывает оценки или задания оттуда автоматически.
